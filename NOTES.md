## SEO push (Oct 2, 2026)
- Site is generated by `build.py` (shared engine, same file in both lead-site repos) + `content.py` (all site-specific copy: cities, guides, FAQs, sources). Edit content.py, then run `python3 build.py`.
- 18 city pages in /areas/, 6 guides in /guides/, breadcrumbs, JSON-LD (WebSite, Organization, Service w/ areaServed, FAQPage, Article, BreadcrumbList). No address/reviews/ratings by design.
- build.py asserts unique titles (<=70 chars) and descriptions (70-165 chars).
- sitemap.xml lastmod = build date; urls.txt lists all indexable URLs (used for IndexNow).
- IndexNow key file: b83e5d0c41f94a2e9c7a6d15e2f08b37.txt. Ping: POST to https://api.indexnow.org/indexnow with host, key, keyLocation (full URL of key file), urlList.
- Note: robots.txt in a project repo is served at /<repo>/robots.txt, which crawlers ignore (only the github.io root robots.txt counts). The sitemap still has to be submitted in GSC/Bing.
- Local facts were checked against official city/county pages in Oct 2026; re-check bulky-item rules yearly.
- Google verification: set GOOGLE_VERIFICATION in content.py (currently empty placeholder) and rebuild.
